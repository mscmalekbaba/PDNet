# Data resources

## MECCANO

- Official dataset repository: https://github.com/fpv-iplab/MECCANO
- Dataset files are not included in this repository. Follow the dataset maintainers' access instructions, terms, and citation requirements.

When documenting a local setup, record the dataset version, split files, preprocessing steps, and any derived annotations used. Do not commit restricted data, personal information, or large dataset artifacts here.
